SyncBoard is a shared whiteboard and code pad built for mock technical interviews — then it plays the whole session back, stroke by stroke, so you can see exactly where you stalled.

Sync

Raw WebSockets with sequence numbers, resumable reconnects, and exponential backoff — no socket.io.

Merge

An RGA sequence CRDT for the code pad and a tombstoned stroke set for the canvas, so concurrent edits converge.

Replay

Every stroke and keystroke is logged as an event and snapshotted, so any session scrubs back at any speed.
